# Building Minimals — static website

This is a static HTML/CSS version of the Building Minimals WordPress export, prepared for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `building-minimals`).
2. Upload the contents of this folder to the repository root. Keep `index.html`, `style.css`, and the `assets` folder at the root level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Included
- Home page
- Real Estate Solutions
- Projects
- Articles index and the two published articles in the WordPress export
- Charts
- Contact
- Shared responsive navigation and styling

Notes: this is a static conversion, not a complete WordPress clone. WordPress plugins, forms, dynamic chart widgets, and some theme-specific behavior do not run on GitHub Pages. Images embedded in the exported page content may still reference the original website's media URLs. The small supplied house sketch is included as the local brand image.
